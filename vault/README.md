# Vault

Estrutura base para uso com Obsidian CLI.

## Organização

- `planos/`
  - planos ativos e roadmap em andamento
- `planos/consolidados/`
  - planos já implementados ou usados como referência histórica

## Convenção

- planos novos entram primeiro em `planos/`
- quando uma fase estiver implementada e estabilizada, o documento pode ser movido para `planos/consolidados/`
- logs técnicos continuam fora da vault enquanto forem documentação operacional do MCP
